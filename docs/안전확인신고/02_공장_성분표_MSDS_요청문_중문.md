# 공장 성분표 / MSDS 요청문 (Lishui Wenqing Toys Co., Ltd.)

위챗·알리바바 채팅에 **그대로 복사해서 보낸다.** 번역하지 말고 원문 그대로 보낼 것.

## 1차 발송 — 자료 요청 (오늘 바로)

```
您好，我是韩国进口商（모모스토어）。

我们正在做韩国KC认证（儿童产品安全确认申报，KATRI试验研究院）。
韩国试验机构要求提供以下资料，没有这些资料检测无法进行，
产品也无法在韩国销售。请务必配合。

【必须提供的资料】
1. MSDS（安全数据表 / SDS）— 英文或中文均可
2. 成分配比表（各成分名称 + CAS号 + 含量百分比，合计100%）
3. 防腐剂：请明确写出使用的防腐剂种类和含量（ppm）
   ※ 韩国禁止 CMIT / MIT。如果使用了，请立即告知
4. 硼（Boron）：是否含有硼砂、硼酸、四硼酸钠？含量多少？
   ※ 韩国液体·粘性玩具的硼溶出限值为 300 mg/kg
5. 塑料容器和盖子的材质名称（PP / PE / PET 等）
6. 每个颜色的成分是否完全相同？
   如果不同，请按颜色分别提供成分表

【如果贵司已有以下报告，请一并发送】
- EN71-3 检测报告
- 韩国KC检测报告（如已做过）
- 硼溶出检测报告
- 防腐剂检测报告
※ 已有报告可以大幅缩短我方检测时间。请先确认后再回复。

【期限】
请在 3 天内提供。超过期限我方将更换供应商。

产品：史莱姆软泥（슬라임 퍼티）
型号：[모델명 기재]
颜色：[색상 전체 기재]

谢谢。
```

## 2차 발송 — 공장이 "没有MSDS" 또는 회피할 때

```
关于MSDS：

1. MSDS 不是可选项，是韩国法律要求的检测必需资料。
   没有MSDS，韩国试验机构不接受样品，检测无法开始。

2. 如果贵司没有正式MSDS文件，请至少提供以下手写/表格形式的资料：
   - 各原料名称 + CAS号 + 含量%（合计100%）
   - 防腐剂名称和含量
   - 是否含硼、含量多少
   加盖公司公章即可。格式不重要，内容必须准确。

3. 如果贵司认为成分是商业机密：
   我方可以签署保密协议（NDA），或者由贵司直接把成分表
   发给韩国试验机构（KATRI），不经过我方。
   这是国际通行做法，请确认贵司是否接受。

4. 如果贵司无法提供任何成分资料，请直接告知。
   我方将立即更换供应商，本次订单取消。

请在24小时内明确回复：能提供 / 不能提供。
```

## 3차 발송 — 성분표 받은 뒤 정합성 확인

```
成分表已收到，谢谢。请再确认以下3点：

1. 成分表上的产品型号，与我方订购的型号是否完全一致？
   如果批次或配方有变更，请立即通知。

2. 出货给我方的产品，配方与成分表100%一致，
   不做任何替换。请书面确认。

3. 今后如果更换原料供应商或调整配方，
   必须提前通知我方。未通知的配方变更，我方有权全批退货。

请回复"确认"即可。
```

---

## 발송 시 반드시 지킬 것

1. **3일 기한을 명시한다.** 기한 없이 보내면 2주 걸린다.
2. **"안 되면 공장 바꾼다"를 1차부터 넣는다.** 이 문장 하나가 회신 속도를 3배로 만든다.
3. **공장이 이미 보유한 EN71-3 / 붕소 성적서를 먼저 묻는다.** 있으면 시험비 절감 + 기간 단축이다. 자비로 전항목 다시 돌리기 전에 반드시 확인한다.
4. 회신이 24시간 내 없으면 **1688에서 슬라임 공장 3곳을 동시 컨택한다.** 한 곳에 매달리지 않는다.
