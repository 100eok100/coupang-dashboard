# 슬라임 퍼티 안전확인 재접수 체크리스트

접수번호 RC26-3860 / 신고확인증 CB064R6421-6001 / KATRI

---

## 왜 막혔나

슬라임·퍼티는 **겔·점착성 완구**로 분류된다. 일반 플라스틱 완구와 시험 항목이 다르다.

| 구분 | 일반 완구 | 슬라임·퍼티(겔) |
|---|---|---|
| 중금속 이행 | 필요 | 필요 |
| 프탈레이트 | 필요 | 필요 |
| **방부제 (CMIT/MIT/BIT 등)** | 불필요 | **필수** |
| **붕소(Boron) 용출** | 불필요 | **필수** |
| 성분표 / MSDS | 대부분 불필요 | **시험 설계에 필수** |

시험기관은 성분표를 봐야 **어떤 방부제를 얼마나 썼는지, 붕사를 넣었는지**를 알고 시험 항목을 확정한다. 성분표 없이는 시험 설계 자체가 안 된다. KATRI 담당자가 요구하는 건 트집이 아니라 겔 제품의 정상 절차다.

## "다들 없이 하고 있다"는 왜 나오는 말인가

그 사람들이 MSDS를 안 낸 게 아니다. **공장이 이미 냈거나, 공장이 KC 성적서를 이미 보유한 것**이다.

- 케이스 A: 중국 공장이 이미 한국 KC 시험을 통과한 성적서 보유 → 셀러는 성적서만 받아 신고. 본인은 MSDS를 만진 적이 없다.
- 케이스 B: 공장이 시험기관에 성분표를 직접 제출 → 셀러는 관여하지 않음.
- 케이스 C: 하드플라스틱 완구 등 겔이 아닌 품목 → 애초에 성분표 요구 대상이 아님.

지금 상황은 A~C 어디에도 해당하지 않는 상태다. 즉 **누군가는 반드시 내야 하는 서류를 아무도 안 낸 상태**다. 여기서 우회를 시도하면 결과는 하나다.

## 우회 시 리스크 (숫자로)

| 리스크 | 결과 |
|---|---|
| 성분표 없이 시험 진행 | 시험 미완료 → 성적서 미발급 → 신고 불성립 |
| 성적서 없이 판매 | 어린이제품 안전 특별법 위반. 판매중지 + 회수 명령 |
| 사후 안전성조사 적발 | 신고 취소 → 쿠팡 전 재고 판매정지, 반품비 셀러 부담 |
| 붕소 초과 (300mg/kg) | 리콜 대상. 슬라임은 국가기술표준원 리콜 최다 품목이다 |

슬라임은 2018년 붕소 검출 사태 이후 **국표원 상시 감시 품목**이다. 다른 완구보다 걸릴 확률이 높다. 통과 여부의 문제가 아니라 시점의 문제다.

## 해결 절차 (총 10~14일)

### D+0 (오늘)
1. `02_공장_성분표_MSDS_요청문_중문.md`의 **1차 발송문**을 공장에 그대로 전송
2. 동시에 KATRI 담당자에게 문의 — "RC26-3860 보완 접수인지, 신규 접수인지" 확인
3. 공장에 **기보유 성적서(EN71-3, 붕소, 방부제)** 유무 질의 — 있으면 시험비 절감

### D+1 ~ D+3
4. 공장 회신 확인. 무응답이면 **2차 발송문(강경) 전송**
5. 24시간 더 무응답이면 1688에서 슬라임 공장 3곳 동시 컨택 시작
6. 성분표 수령 → 방부제 종류·붕소 함량 확인
   - CMIT / MIT 검출 → **즉시 공장 교체.** 한국 어린이제품 사용 금지 성분이다
   - 붕사(硼砂) 사용 → 함량 확인. 300mg/kg 용출 기준 초과 위험이면 무붕사 배합 요구

### D+3 ~ D+4
7. KATRI에 성분표 제출 → 시험 항목 확정 → 시료 발송
   - 시료는 **판매 예정 완제품 상태**로, 색상별 각 3개 이상
   - 시험 신청서 시료명은 **신고서 모델명(슬라임 퍼티)과 100% 일치**시킨다

### D+5 ~ D+12
8. 시험 진행 (겔 제품 방부제·붕소 포함 시 통상 7~10영업일)
9. 성적서 수령

### D+12 ~ D+14
10. 신고서 재작성 (`01_안전확인신고서_작성본_슬라임퍼티.md` 그대로 전사)
11. 첨부 3종 준비: 사업자등록증 사본 / 제품 설명서(사진 4컷 이상) / 시험 결과서
12. KATRI 접수 → 처리기간 7일

## 주의사항

1. **경쟁사가 MSDS 없이 신고했다는 사실은 근거가 아니다.** 신고는 상품 단위로 들어간다. 그 셀러의 통과 사유(공장 기보유 성적서 등)를 모르는 상태에서 따라가면 그대로 사고다.
2. **공장 구두 확인은 효력 0이다.** "우리 제품 붕사 없어요"는 문서가 아니면 없는 것이다. 반드시 공장 직인 찍힌 문서로 받는다.
3. **색상별 배합이 다르면 성분표도 색상별로 받는다.** 이걸 놓쳐서 시험 재의뢰하는 케이스가 가장 많다.
4. **배합 변경 통보 조항을 발주서에 넣는다.** 공장이 원료 공급처를 바꾸면 기존 성적서는 무효다.
5. **붕소 용출 기준(액체·점착성 완구 300mg/kg)과 방부제 세부 기준은 시료 발송 전 KATRI 담당자에게 최종 확인한다.** 기준값이 개정되는 품목이다.
6. **상세페이지에 "무독성", "친환경", "안전 인증" 문구 금지.** 신고확인증은 인증이 아니다. 표기는 `KC 안전확인 신고번호 CB064R6421-6001` 형식으로만 한다.

3. 1688에서 슬라임/퍼티 공장 3곳 검색 후 동일 요청문 발송 — 현 공장이 못 주면 바로 갈아탄다
