# 공장에 MSDS가 없을 때 — 대체 경로 4단계

전제: 시험기관이 원하는 건 **MSDS라는 문서 양식**이 아니라 **성분 정보**다.
양식은 대체 가능하다. A → B → C → D 순서로 밀어붙인다. 위에서 뚫리면 아래는 안 한다.

---

## A안. 배합표(成分配比表) + 공장 직인 — 1순위, 2~3일

정식 MSDS는 작성 비용·시간이 들어 중소 공장은 대부분 없다. 하지만 **배합표는 100% 갖고 있다.** 없으면 생산이 안 된다.
A4 한 장에 성분명 + CAS번호 + 함량% 적고 공장 직인 찍으면 시험기관은 이걸 MSDS 대신 받는다.

```
关于MSDS的回复，我方理解。

正式MSDS文件不是必须的。我方需要的是"成分信息"，格式可以替代。
请提供以下任意一种即可（A4一页，盖公司公章）：

【方案1 — 成分配比表】
| 成分名称 | CAS号 | 含量% |
|---|---|---|
|  |  |  |
合计必须为100%。
※ CAS号如果查不到，写成分中文名+英文名也可以。

【方案2 — 如果配方属于商业机密】
不需要公开全部配方。只需要书面确认以下4项：
1. 是否含有硼砂 / 硼酸 / 四硼酸钠？含量多少 ppm？
2. 使用的防腐剂名称是什么？含量多少 ppm？
3. 是否含有 CMIT / MIT？（韩国禁止使用）
4. 是否含有邻苯二甲酸酯类增塑剂（Phthalates）？

这4项写在一页纸上，盖公章即可。
不需要正式MSDS格式。

请在3天内提供。这是韩国法律要求，没有这个资料检测无法进行。
```

## B안. 불사용 확인서(声明书) — A안 거부 시, 1~2일

배합 공개를 거부해도 **"안 들어갔다"는 확인서**는 대부분 써준다. 책임이 공장에 남기 때문에 오히려 이걸 더 꺼리는 공장도 있지만, 정상 공장이면 써준다.

```
如果配方完全不能公开，请至少出具以下声明书。
一页纸，盖公司公章，负责人签字。

—————————————————————
　　　　　　成 分 声 明 书
　　　DECLARATION OF COMPOSITION

产品名称：史莱姆软泥（Slime Putty）
型号：[모델명]
生产厂家：Lishui Wenqing Toys Co., Ltd.

我司声明，上述产品：

1. 硼元素（Boron）：□ 不含　□ 含有，含量　　 ppm
2. 防腐剂：□ 未使用　□ 使用，名称　　　　，含量　　 ppm
3. CMIT / MIT：□ 未使用
4. 邻苯二甲酸酯（Phthalates）：□ 未使用
5. 重金属（铅、镉、汞、六价铬等）：□ 未添加

我司对以上内容的真实性负法律责任。
如因成分申报不实导致韩国检测不合格或产品召回，
本公司承担全部损失及赔偿责任。

公司名称：
负责人签字：
公　　章：
日　　期：　　年　　月　　日
—————————————————————

请把这份声明书打印、盖章、拍照或扫描后发给我。
```

**"如因申报不实...承担全部赔偿责任" 문장은 반드시 넣는다.** 이 문장이 있어야 나중에 리콜 났을 때 공장에 구상권이 선다. 이 문장 때문에 거부하는 공장은 성분에 문제가 있는 것이다. 그 자체가 판단 근거다.

## C안. MSDS 대행 작성 — A·B 병행 가능, 3~5일 / 300~800위안

중국에는 MSDS 작성 대행업체가 흔하다. 공장이 배합비만 넘기면 대행업체가 정식 MSDS를 만들어준다. 공장이 "만들 줄 몰라서" 없다고 하는 케이스가 절반이다.

```
如果贵司只是没有做过MSDS、不知道怎么写，这个问题很好解决。

中国有很多MSDS代写机构，费用大约300~800元，3~5个工作日出。
贵司只需要把配方提供给代写机构即可，不用给我方。

请贵司联系一家代写机构制作MSDS。
费用我方承担，请告知金额，我方转账。

如果贵司不愿意联系，请把代写机构联系方式给我，我方直接对接。
```

비용을 셀러가 부담하겠다고 먼저 말한다. 800위안(약 16만원)이면 공장 교체 비용보다 훨씬 싸다. 여기서 아끼지 않는다.

---

## D안. 성분 자료 없이 전항목 스크리닝 시험 — 최후 수단

성분표의 본래 목적은 **시험 항목을 좁혀 비용을 줄이는 것**이다. 성분을 모르면 좁힐 수가 없으니 **전부 돌리면 된다.** 불가능한 게 아니라 비싸질 뿐이다.

| 구분 | 성분표 있음 | 성분표 없음 |
|---|---|---|
| 방부제 | 신고된 물질만 정량 | 방부제 전항목 스크리닝 |
| 붕소 | 함유 시에만 용출시험 | 무조건 용출시험 |
| 시험 기간 | 7~10영업일 | 10~15영업일 |
| 비용 | 기준 | 상승 |

**KATRI 담당자에게 이 문장 그대로 물어본다:**

> "제조사에서 MSDS와 성분표를 제공하지 못합니다. 성분 자료 없이 전항목 스크리닝으로 시험 접수가 가능한지, 가능하다면 추가되는 항목과 견적을 알려주십시오. 접수번호 RC26-3860 건입니다."

여기서 "가능하다"가 나오면 **오늘 시료 보내고 끝난다.** 이 한 통화를 먼저 해야 한다.

## 판정 기준 — 여기서 걸리면 공장을 바꾼다

아래 중 하나라도 해당하면 **성분에 문제가 있는 공장**이다. 미련 없이 교체한다.

1. A·B·C 전부 거부 — 배합표도, 확인서도, 대행 작성도 안 한다
2. 확인서에 "법적 책임" 문장을 못 넣겠다고 한다
3. CMIT / MIT 사용을 시인한다 → **즉시 중단.** 한국 어린이제품 사용 금지 성분이다
4. 붕사 함량을 답하지 못한다 → 슬라임 공장이 붕사 함량을 모르는 경우는 없다. 숨기는 것이다
5. 3일 기한 무응답 2회

슬라임 공장은 1688에 수백 곳이다. 대체 불가능한 공장이 아니다. **한 곳에 매달려 2주를 태우는 게 최악의 시나리오다.**

| 순번 | 행동 | 소요 |

| 2 | 공장에 A안 + B안 메시지 동시 발송 (둘 중 아무거나 달라고 한다) | 5분 |
| 3 | 공장이 "만들 줄 모른다" 반응이면 즉시 C안 발송 | 5분 |
| 4 | 1688에서 슬라임 공장 3곳 컨택, 동일 자료 요청 | 30분 |

1번을 먼저 한다. D안이 되면 나머지는 보험이다.
