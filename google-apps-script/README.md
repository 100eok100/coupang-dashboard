# 창고 날씨 알림 — 구글 앱스 스크립트

Netlify 로그인 없이 구글 계정만으로 돌아갑니다. 매일 아침 7시대에 Gmail로 오고, 카카오를 연결하면 카카오톡 "나와의 채팅"으로도 옵니다.

## 1. Gmail로 받기 (5분)
휴대폰 크롬 → 메뉴(⋮) → [데스크톱 사이트] 체크 후 진행

1. [weather-alert.gs 원본](https://raw.githubusercontent.com/100eok100/coupang-dashboard/claude/ulsan-warehouse-weather-alerts-s3m09y/google-apps-script/weather-alert.gs) 열기 → 화면 길게 눌러 [전체 선택] → [복사]
2. https://script.google.com 접속 → [새 프로젝트]
3. 편집기에 있던 `function myFunction() {}` 지우고 붙여넣기
4. 위쪽 `LAT`, `LON` 숫자를 창고 좌표로 바꾸기 (구글 지도에서 창고 위치를 길게 누르면 맨 위에 `35.xxxx, 129.xxxx` 표시)
5. 저장(디스크 아이콘)
6. 위쪽 함수 선택이 `setup` 인지 확인 → [실행]
7. [권한 검토] → 구글 계정 선택 → "확인되지 않은 앱" 화면에서 [고급] → [(프로젝트 이름)(으)로 이동] → [허용]
8. Gmail에 "[울산 창고] 내일 ..." 메일이 오면 완료. 다음 날부터 매일 자동 발송

## 2. 카카오톡도 받기 (10분, 선택)
1. https://developers.kakao.com/console/app → 카카오 로그인 → [애플리케이션 추가하기] → 이름 "창고날씨" → 저장
2. [앱 키] → REST API 키 복사 → 스크립트 맨 위 `KAKAO_REST_API_KEY = '여기'` 에 붙여넣기 → 저장
3. 스크립트 편집기 [배포] → [새 배포] → 유형 [웹 앱] → 실행: 나 / 액세스: 나만 → [배포] → 웹 앱 URL 복사
4. 카카오 디벨로퍼스 [카카오 로그인] → 활성화 ON → Redirect URI에 3번 웹 앱 URL 붙여넣기 → 저장
5. [카카오 로그인] → [동의항목] → "카카오톡 메시지 전송" → 선택 동의 → 저장
6. 휴대폰에서 3번 웹 앱 URL 접속 → [카카오톡 연결하기] → 동의 → 카카오톡 "나와의 채팅"에 테스트 메시지 확인

## 판정 기준
- 비: 강수확률 60% 이상 또는 강수량 5mm 이상 → 박스 실내 보관 · 상차 전 방수비닐 포장
- 강풍: 최대풍속 10m/s 이상 → 야외 적재 금지 · 파렛트 랩핑 고정
- 비 시간: 1시간 강수량 0.5mm 이상 또는 강수확률 60% 이상인 시간을 묶어 "06~11시"처럼 표시 (카톡: 오늘·내일 최대 3구간 + 주간 첫 구간, 메일: 7일 전체)

## 바꾸는 법
- 발송 시각: `SEND_HOUR` 수정 → 저장 → `setup` 다시 실행 (구글 예약은 지정 시각부터 1시간 안에 실행됨)
- 그만 받기: 편집기 왼쪽 시계 아이콘 [트리거] → `dailyAlert` 삭제
