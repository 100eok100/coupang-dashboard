모니터 "주파수 초과" 해결

모니터 고장 아님. 설정만 바꾸면 됩니다. 화면이 잘 나오는 모니터에서 위에서부터 순서대로 하세요.

지금 할 것 (딱 이것만)

  1. 바탕화면 오른쪽 클릭 → 디스플레이 설정
  2. 식별 → 숫자 안 뜨는 모니터 번호 클릭
  3. 해상도 (권장)
  4. 고급 디스플레이 → 새로 고침 빈도 60Hz

원인 선은 정상

  • 선 3개 모두 아래쪽 그래픽카드에 꽂힘 = OK
  • 컴퓨터가 모니터가 감당 못 하는 속도(Hz)로 화면을 보내서 생기는 문제

STEP 1. 디스플레이 설정 열기

  1. 바탕화면 빈 곳에서 마우스 오른쪽 클릭
  2. 디스플레이 설정 클릭

STEP 2. 안 나오는 모니터 찾기

  1. 화면 위쪽에 네모 칸 1, 2, 3 확인
  2. 식별 버튼 클릭 → 각 모니터에 숫자가 크게 뜸
  3. 숫자가 안 뜨는 모니터 = 문제 모니터
  4. 위쪽 네모 칸 중 그 번호를 클릭

STEP 3. 해상도 맞추기

  1. 아래로 내려서 디스플레이 해상도
  2. 목록에서 (권장) 이라고 써 있는 것 선택

STEP 4. 주파수 낮추기

  1. 같은 화면 더 아래 고급 디스플레이 클릭
  2. 새로 고침 빈도 → 60Hz 선택
  3. "변경 내용 유지" 창 뜨면 유지 클릭

그래도 안 될 때

상황할 일
화면이 순간 꺼졌다 켜짐정상. 15초 기다리면 원래대로 돌아옴
그래픽 화면 먹통Win + Ctrl + Shift + B 동시에 누르기 (그래픽 리셋, 삐 소리 남)
3대 모두 화면 안 나옴이 방법 불가 → 바로 알려주기
60Hz로 나왔음한 칸씩 올려보기. 다시 초과 뜨면 한 칸 내리기

주의사항

  • 모니터 선은 무조건 아래쪽(그래픽카드)에만 꽂기
  • 위쪽(메인보드) 구멍은 화면 안 나옴
