창고 날씨 카카오톡 알림

매일 07:00 카카오톡 "나와의 채팅"으로 오늘·내일·7일 비 예보 발송. 위에서부터 순서대로 하세요.

1. 비밀번호 미설정

처음 입력한 값이 비밀번호로 등록됩니다. 4자 이상.

2. 창고 위치 울산 시내 기준

창고에 서서 누르세요. 위치 권한을 물으면 [허용].

3. 카카오 앱 만들기 미설정

  1. 카카오 디벨로퍼스 접속 → 카카오 로그인 → [애플리케이션 추가하기] → 앱 이름 "창고날씨" → 저장
  2. [플랫폼] → [Web 플랫폼 등록] → 사이트 도메인에 아래 주소 붙여넣기
  3. [카카오 로그인] → 활성화 ON → Redirect URI에 아래 주소 붙여넣기
  4. [카카오 로그인] → [동의항목] → "카카오톡 메시지 전송" → [설정] → 선택 동의 → 저장
  5. [앱 키] → "REST API 키" 복사 → 아래 칸에 붙여넣기

4. 카카오톡 연결 미연결

날씨를 받을 본인 카카오 계정으로 로그인 → [동의하고 계속하기].
